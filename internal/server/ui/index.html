              About Culprit

              Projects fix security bugs all the time without saying so. The commit reads "tidy frame reader" or "small fix", and the vulnerability it closes was live in every release before it.

              Culprit reads a repository's history and scores each commit on three kinds of evidence: what the message says, what the diff adds, and which files it touches. A commit that adds a bounds check to a parser, swaps a token comparison for a constant-time one, or starts cleaning file paths scores high. If it never mentions a CVE or the word security, it is marked as a silent fix.

              The scores are a reading order, not a verdict. Start at the top of the list and read the diffs.
